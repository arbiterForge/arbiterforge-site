# arbiterforge-site

Public static site for arbiterforge.com in arbiterForge/arbiterforge-site. Main
receives PRs; CNAME retains the custom domain. The homepage uses inline CSS/JS
and local fonts. Jekyll renders news from _data/arbiter_news, _layouts and _includes.
Existing tests preserve edition, archive, coverage and RSS contracts.

The user requested actual SIM at /SIM beside news, as a first tools entry for a
possible living resume. The scoped feature composes existing Jekyll output and
the published SUaDtL/SIM main preview into one Pages deployment. SIM source and
release ownership remain upstream. No backend, app behavior change or whole-site
resume redesign is included. Main pushes and a 20-minute poll update the site.

See tech-stack.md, security-controls.md and the canonical host-sim HTML spec/plan.
Implementation progress does not imply hosted CI, merge, deployment or receiving.
